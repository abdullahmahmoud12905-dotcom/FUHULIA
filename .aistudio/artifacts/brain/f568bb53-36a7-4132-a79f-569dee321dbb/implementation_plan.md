# خطة استعادة الإعدادات السابقة وتطوير Copilot مع إخفاء أشرطة التمرير

خطة شاملة للاستجابة المباشرة لجميع ملاحظاتك المؤكدة: استعادة النسخة المحفوظة السابقة للأيقونات والإعدادات، وتضمين زر الإعدادات (الترس) في ترويسة Copilot مع إتاحة تفعيل وتعطيل وضع التخطيط (Plan Mode) بداخله، وتوحيد شريط البحث في Taskbar، وإخفاء أشرطة التمرير (Scrollbars) بالكامل في حقل الإدخال الذكي وكافة نوافذ ويندوز.

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد الخيارات الثلاثة الحاسمة وفق إجاباتك الصريحة:

- **القرار المؤكد 1 (استعادة الإعدادات والأيقونات السابقة)**: استعادة النسخة المحفوظة السابقة فوراً للإعدادات وأيقونات سطح المكتب وترتيبها مع الحفاظ التام على جميع التطبيقات والملفات الحالية دون أي فقدان.
- **القرار المؤكد 2 (موضع وضع التخطيط Plan Mode وإعدادات Copilot)**: إضافة زر الترس في ترويسة Copilot (والشات المصغر) يفتح لوحة إعدادات شاملة، ويكون زر تفعيل/تعطيل وضع التخطيط (Plan Mode) مدمجاً بداخلها في تبويب أوضاع التشغيل، مع بطاقات المهام التفاعلية للموافقة قبل التنفيذ.
- **القرار المؤكد 3 (إخفاء أشرطة التمرير Scrollbars كلياً)**: إخفاء أشرطة التمرير بالكامل في حقل الإدخال ذاتي التمدد وجميع نوافذ وتطبيقات النظام عبر فئات CSS العالمية (`scrollbar-none`, `overflow-hidden`, `::-webkit-scrollbar { display: none; }`) لمنح النظام مظهراً عصرياً ونقياً بنسبة 100%.

### 1. Overview & Core Concept

- **What It Does**:
  1. **الاستعادة الفورية**: استرجاع كامل الإعدادات والأيقونات السابقة لسطح المكتب دون التعديل على أي تطبيق مثبت.
  2. **زر الإعدادات ووضع التخطيط في Copilot**: زر ترس أنيق في ترويسة Copilot يفتح لوحة إعدادات متكاملة تضم تفعيل "وضع التخطيط (Plan Mode)"، وإدارة الذاكرة السياقية (1M)، وإدارة الجلسات، وتفضيلات التوليد (منع الإيموجيز).
  3. **تنفيذ وضع التخطيط (Plan Mode Workflow)**: عند تفعيل Plan Mode وطلب تعديل تطبيق أو بناء مشروع، يتم توليد خطة مهام منظمة مع زر "الموافقة والتنفيذ" ولا يتم التعديل إلا بعد موافقة المستخدم.
  4. **شريط بحث موحد في Taskbar**: شريط بحث Windows 11 الأصلي الموحد في منتصف شريط المهام مع أيقونات Windows 11 Pro الرسمية فائقة الدقة.
  5. **إخفاء أشرطة التمرير نهائياً**: إزالة ظهور أشرطة التمرير التقليدية من حقل إدخال Copilot ومن جميع نوافذ وتطبيقات النظام مع بقاء إمكانية التمرير بالماوس أو اللمس بسلاسة تامة.
- **Target Audience / Persona**: المستخدم ومطورو النظام الذين يطلبون مظهراً بصرياً متناسقاً وخالياً من التشويش، مع تحكم دقيق وإذن مسبق قبل تنفيذ التعديلات.
- **Key Value**: تلبية طلبات المستخدم الحرفية دون أي تغيير غير مرغوب فيه، وتوفير أقصى درجات النقاء البصري والتحكم المؤسسي.

### 2. User Experience & Visual Design

#### Key User Flows:
1. **استعادة سطح المكتب والإعدادات**:
   - استدعاء بيانات الأيقونات والإعدادات السابقة من التخزين التراكمي وتطبيقها فوراً دون المساس بالملفات.
2. **لوحة إعدادات Copilot عبر زر الترس**:
   - النقر على زر الترس المدمج في ترويسة Copilot يفتح نافذة منسقة (Fluent Acrylic) تضم:
     - **تبويب الوضع (Mode)**: تفعيل أو تعطيل وضع التخطيط (Plan Mode) مع شرح واضح لآلية توليد المهام للموافقة قبل التنفيذ.
     - **تبويب الذاكرة (Memory)**: عرض الذاكرة المستخدمة (من 1,000,000 حرف)، ومسح الذاكرة أو مراجعتها.
     - **تبويب الجلسات (Sessions)**: إنشاء محادثة جديدة، واستعراض وحذف الجلسات.
     - **تبويب التفضيلات (Custom Instructions)**: تخصيص التعليمات وتفعيل خيار "منع الإيموجيز".
3. **تجربة وضع التخطيط (Plan Mode)**:
   - عند تفعيل الوضع من الإعدادات، يظهر مؤشر هادئ "Plan Mode Active".
   - أي طلب لتعديل الحاسبة، المفكرة، أو بناء مشروع يولد بطاقة خطة مهام منظمة بها خطوات محددة وزر "الموافقة والتنفيذ"، وعند الضغط عليه فقط يبدأ التنفيذ البرمجي.
4. **حقل الإدخال فائق النقاء والنوافذ بدون Scrollbars**:
   - حقل الكتابة يتمدد تلقائياً من سطر إلى عدة أسطر حسب النص مع إخفاء تام لشريط التمرير (دون أن يظهر أي شريط رمادي مزعج).
   - تطبيق إخفاء أشرطة التمرير على مستوى النظام بالكامل في ملف التنسيق العام (`index.html` / global CSS) عبر قواعد التمرير المخفي.

### 3. Key Product Decisions & Trade-Offs

#### Decision 1: استعادة الإعدادات والأيقونات السابقة مع الحفاظ على التطبيقات
- **Chosen Approach**: استعادة إعدادات وأيقونات سطح المكتب السابقة من الذاكرة المحلية مع الحفاظ على كافة التطبيقات والملفات المنشأة، دون فرض أي تغيير عشوائي.
- **Why**: استجابة مباشرة لطلب المستخدم بعدم تغيير إعدادات النظام بدون إذنه.

#### Decision 2: وضع التخطيط (Plan Mode) كخيار داخل إعدادات الترس
- **Chosen Approach**: وضع محول التبديل داخل نافذة إعدادات Copilot المفتوحة بزر الترس، ليبقى شريط المحادثة نظيفاً ومنظماً.
- **Why**: التزام كامل باختيار المستخدم الصريح في الاستبيان.

#### Decision 3: إخفاء أشرطة التمرير في النظام كلياً (Invisible Scrollbars)
- **Chosen Approach**: إضافة قاعدة CSS عامة لإخفاء مظهر أشرطة التمرير عبر المتصفح (`* { scrollbar-width: none; -ms-overflow-style: none; } *::-webkit-scrollbar { display: none !important; }`) مع الحفاظ على قدرة التمرير بعجلة الماوس أو السحب.
- **Why**: إزالة أي مظهر غير لائق لأشرطة التمرير وتحقيق نقاء Fluent Design بالكامل.

#### Core Components & File Updates:
1. `index.html` & Global Styles:
   - تطبيق قاعدة إخفاء أشرطة التمرير كلياً (`::-webkit-scrollbar { display: none !important; }` و `scrollbar-width: none`).
2. `src/components/apps/CopilotApp.tsx`:
   - إضافة زر الترس (⚙️) في الترويسة لفتح نافذة إعدادات Copilot المتكاملة.
   - تضمين تبويب الأوضاع لاختيار Plan Mode أو Default Mode وتخزينه في الإعدادات.
   - إضافة بطاقة عرض خطة المهام التفاعلية مع زري "الموافقة والتنفيذ" و"تعديل الخطة".
   - تطبيق إخفاء شريط التمرير في حقل الإدخال ذاتي التمدد.
3. `src/App.tsx`:
   - استعادة الإعدادات والأيقونات السابقة والحفاظ التام على التطبيقات.
   - التأكد من توحيد شريط البحث بنمط Windows 11 Pro الرسمي.
   - إضافة زر الترس في ترويسة الشات المصغر (Mini Copilot).
4. `server.ts`:
   - استمرار تفعيل معالجة Plan Mode وإصدار خطة المهام المنظمة عند الطلب قبل التنفيذ.

### 5. Verification & Test Plan

1. **التحقق من إخفاء أشرطة التمرير**: فتح حقل إدخال Copilot وكتابة نصوص طويلة والتأكد من تمدد الحقل بدون ظهور أي شريط تمرير، مع اختبار النوافذ الأخرى والتأكد من اختفاء أشرطة التمرير مع بقاء إمكانية التمرير بسلاسة.
2. **التحقق من زر الإعدادات في Copilot**: النقر على زر الترس في الترويسة والتأكد من فتح نافذة الإعدادات بتبويباتها (الأوضاع، الذاكرة، الجلسات، التفضيلات).
3. **التحقق من وضع التخطيط (Plan Mode)**: تفعيل الوضع من داخل الإعدادات، ثم إرسال طلب لتعديل تطبيق أو مشروع والتأكد من ظهور بطاقة خطة المهام المقترحة خطوة بخطوة وعدم تعديل أي ملفات إلا بعد ضغط "الموافقة والتنفيذ".
4. **التحقق من شريط البحث والأيقونات**: التحقق من ظهور شريط البحث الموحد والأيقونات الأصلية المستعادة دون أي تغيير غير مقصود.
5. **التحقق من البناء**: تشغيل `compile_applet` و `lint_applet` للتأكد من خلو المشروع تماماً من أي أخطاء.
